SimContainer

class SimContainer(env, name: String, capacity: Double, initialLevel: Double = 0.0)

SimContainer modela um recipiente de quantidade contínua com capacidade finita. Processos adicionam (ctx.put()) e retiram (ctx.get()) quantidades, suspendendo automaticamente quando não há espaço ou quantidade suficiente. Use para modelar tanques de combustível, baterias, reservatórios de água, estoques numéricos.

Criação

// Tanque de combustível começando vazio
val tanque = env.container("tanque", capacity = 500.0)

// Bateria começando cheia
val bateria = env.container("bateria", capacity = 100.0, initialLevel = 100.0)

Propriedades

PropriedadeTipoDescrição
nameStringIdentificador do recipiente.
capacityDoubleCapacidade máxima.
levelDoubleNível atual. Leitura direta — não suspende.

Métodos

MétodoRetornoDescrição
put(amount: Double): SimEvent<Unit>SimEventAdiciona amount ao nível. Suspende se não houver espaço suficiente.
get(amount: Double): SimEvent<Unit>SimEventRemove amount do nível. Suspende se o nível atual for insuficiente.
available()DoubleEspaço livre: capacity - level.

Exemplo: posto de combustível simplificado

val env = Environment()
val tanque = env.container("underground-tank", capacity = 500.0, initialLevel = 300.0)

// Carro chega e abastece
env.process(SimProcess { ctx ->
    val necessidade = 80.0
    ctx.env.monitor.record(ctx.now,
        "Carro chegou (tanque: ${tanque.level}L)")

    ctx.get(tanque, necessidade)  // suspende se não tiver combustível
    ctx.env.monitor.record(ctx.now,
        "Carro abasteceu ${necessidade}L (restam: ${tanque.level}L)")
    ctx.hold(4.0)  // tempo de abastecimento
})

// Caminhão de reabastecimento
env.process(SimProcess { ctx ->
    ctx.hold(2.0)
    ctx.env.monitor.record(ctx.now, "Caminhão chegou")
    ctx.put(tanque, 150.0)
    ctx.env.monitor.record(ctx.now,
        "Reabastecimento concluído (tanque: ${tanque.level}L)")
})

env.run(until = SimTime(10.0))
env.monitor.printAll()

Saída esperada

[SimTime(value=0.0)]: Carro chegou (tanque: 300.0L) [SimTime(value=0.0)]: Carro abasteceu 80.0L (restam: 220.0L) [SimTime(value=2.0)]: Caminhão chegou [SimTime(value=2.0)]: Reabastecimento concluído (tanque: 370.0L)

Combinando com SimContinuousModel

Use SimContinuousModel para drenar o container em taxa constante e SimProcess para eventos discretos (como ligar o modo econômico). Veja o exemplo completo em Bateria e Sensores. 

val bateria = env.container("bateria", capacity = 100.0, initialLevel = 100.0)

// Drena 2% por unidade de tempo
val drainModel = SimContinuousModel { ctx, dt ->
    val drain = 2.0 * dt
    val atual = minOf(drain, bateria.level)
    if (atual > 0.0) bateria.get(atual)
}

env.continuous(stepSize = 1.0, models = arrayOf(drainModel))
env.run(until = SimTime(60.0))

println("Bateria restante: ${bateria.level}%")
amount deve ser > 0. A chamada lança IllegalArgumentException se zero ou negativo for passado.
