SimProcess

fun interface SimProcess { suspend fun run(context: SimProcessContext) }

SimProcess é a abstração central do SimKT. Representa um comportamento sequencial que avança no tempo virtual chamando ctx.hold(), espera por eventos com ctx.await(), e interage com primitivos via ctx.request(), ctx.send(), etc.

Sem kotlinx.coroutines. O SimKT usa a API de coroutines de baixo nível do Kotlin (startCoroutine + suspendCoroutine), drivenada pelo próprio scheduler. Você não precisa de nenhuma dependência extra.

Como usar

Como é uma fun interface, você pode usar uma lambda. O parâmetro ctx é um SimProcessContext — o único ponto de entrada para interagir com a simulação de dentro de um processo. 

// Forma lambda (mais comum)
val processo = SimProcess { ctx ->
    ctx.hold(5.0)
    ctx.env.monitor.record(ctx.now, "acordou")
}

// Classe explícita (quando precisar de estado interno)
class SensorPeriodico(val intervalo: Double) : SimProcess {
    override suspend fun run(context: SimProcessContext) {
        while (true) {
            context.hold(intervalo)
            context.env.monitor.record(context.now, "leitura")
        }
    }
}

// Registro no Environment
env.process(processo)
env.process(SensorPeriodico(10.0))

Como processos são executados

  1. env.process(p) chama p.run.startCoroutine(...).
  2. A coroutine começa a executar imediatamente até o primeiro ponto de suspensão (hold, await, etc.).
  3. No ponto de suspensão, um Continuation é criado e armazenado dentro do SimEvent correspondente.
  4. O scheduler avança. Quando o evento é atingido, ele chama event.trigger(), que chama continuation.resume().
  5. A coroutine retoma exatamente de onde parou.
Nenhuma thread é bloqueada. O processo existe apenas como um objeto Continuation na memória enquanto está suspenso.

Padrões comuns

Loop infinito (processo persistente)

env.process(SimProcess { ctx ->
    while (true) {
        ctx.hold(10.0)
        ctx.env.monitor.record(ctx.now, "evento periódico")
    }
})
// O loop para quando env.run(until = ...) atingir o limite

Processo finito

env.process(SimProcess { ctx ->
    ctx.hold(5.0)
    ctx.env.monitor.record(ctx.now, "passo 1")
    ctx.hold(3.0)
    ctx.env.monitor.record(ctx.now, "passo 2")
    // termina — a coroutine encerra normalmente
})

Processo com estado interno

env.process(SimProcess { ctx ->
    var bateria = 100.0
    val drainRate = 5.0

    while (bateria > 0) {
        ctx.hold(1.0)
        bateria -= drainRate
        ctx.env.monitor.record(ctx.now, "bateria: $bateria%")

        if (bateria <= 20.0) {
            ctx.env.monitor.record(ctx.now, "alerta: bateria baixa")
        }
    }

    ctx.env.stop()  // para a simulação quando a bateria zerar
})

Iniciando processos de dentro de outro processo

env.process(SimProcess { ctx ->
    ctx.hold(5.0)
    // Inicia um segundo processo em t=5
    ctx.env.process(SimProcess { inner ->
        inner.hold(3.0)
        inner.env.monitor.record(inner.now, "processo filho concluído")
    })
    ctx.env.monitor.record(ctx.now, "processo pai continua")
})
