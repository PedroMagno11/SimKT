Environment

class Environment(clock, scheduler, monitor, random)

Environment é a fachada central da simulação. Ele mantém o relógio virtual, a fila de eventos e expõe os métodos para criar processos, primitivos e executar o loop. Todos os outros componentes recebem uma referência a ele.

Construtor

Todos os parâmetros têm valores padrão — na maioria dos casos basta Environment().

ParâmetroTipoPadrãoDescrição
clockSimClockSimClock()Relógio interno. Raramente precisará ser substituído.
schedulerSimSchedulerPriorityQueueScheduler()Implementação da fila de eventos.
monitorSimMonitorSimMonitor()Log de eventos. Acessível via env.monitor.
randomSimRandomProviderSimRandomProvider()RNG. Acessível via env.random. Use SimConfig para seed.

Propriedades

PropriedadeTipoDescrição
nowSimTimeTempo atual da simulação. Avança apenas quando o scheduler processa eventos.
monitorSimMonitorLog de texto. Use env.monitor.record(now, msg) e env.monitor.printAll().
randomSimRandomProviderRNG com seed opcional. Use para resultados reproduzíveis.

Agendamento de eventos

MétodoRetornoDescrição
timeout(delay: Double, action: () -> Unit = {})SimEvent<Unit>Agenda um evento para now + delay. delay deve ser ≥ 0.
timeout(delay: Long, action: () -> Unit = {})SimEvent<Unit>Variante com Long (convertida para Double internamente).
eventAt(time, value?, action?)SimEvent<T>Agenda um evento para um tempo absoluto específico.
eventNow(value?, action?)SimEvent<T>Agenda um evento no tempo atual (now).
schedule(event: SimEvent<*>)UnitAdiciona um evento já criado à fila. Lança erro se event.time < now.

Processos

MétodoDescrição
process(process: SimProcess)Registra e inicia uma coroutine. O processo começa imediatamente até o primeiro hold() ou await().
 
env.process(SimProcess { ctx ->
    ctx.hold(5.0)
    ctx.env.monitor.record(ctx.now, "acordou")
})

Criação de primitivos

Todos os primitivos são criados pelo Environment para que recebam a referência ao relógio e ao scheduler.

MétodoRetornoDescrição
resource(name: String, capacity: Int)SimResourceRecurso compartilhado com fila de espera FIFO.
channel<T>(name: String, capacity: Int = MAX)SimChannel<T>Canal FIFO tipado com backpressure.
store<T>(name: String, capacity: Int = MAX)SimQueue<T>Fila de objetos com producers e consumers suspensos.
container(name: String, capacity: Double, initialLevel: Double = 0.0)SimContainerRecipiente numérico contínuo (combustível, bateria, água).
continuous(stepSize: Double, until: SimTime? = null, vararg models)UnitRegistra modelos contínuos executados a cada stepSize unidades de tempo.

Execução

MétodoDescrição
run(until: SimTime? = null, maxEvents: Long? = null)Executa o loop até o limite de tempo, de eventos, ou até a fila se esgotar.
run(config: SimConfig)Executa com configuração declarativa. Aplica seed aleatório se config.randomSeed for fornecido.
run()Atalho: roda até a fila se esgotar (sem limite de tempo).
stop()Interrompe o loop da próxima iteração. Pode ser chamado de dentro de um processo.
reset()Limpa relógio, fila, monitor e contador de processos. Útil para rodar múltiplos cenários.

Exemplos

Simulação básica com processo

val env = Environment()

env.process(SimProcess { ctx ->
    ctx.hold(10.0)
    ctx.env.monitor.record(ctx.now, "evento executado")
})

env.run(until = SimTime(20.0))
env.monitor.printAll()
// [SimTime(value=10.0)]: evento executado

Parar a simulação de dentro de um processo

env.process(SimProcess { ctx ->
    repeat(10) {
        ctx.hold(1.0)
        if (ctx.now.value >= 3.0) ctx.env.stop()
    }
})
env.run()
// Para em t=3.0

Configuração com seed para reprodutibilidade

val env = Environment()

env.process(SimProcess { ctx ->
    val intervalo = ctx.env.random.nextDouble(1.0, 10.0)
    ctx.hold(intervalo)
})

env.run(SimConfig(until = SimTime(100.0), randomSeed = 42L))
O Environment não é thread-safe por design. Toda a simulação roda em uma única thread — isso é intencional e garante determinismo.
