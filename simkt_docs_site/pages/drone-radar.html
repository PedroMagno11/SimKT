Drone e Radar

Um radar detecta um drone em movimento e publica o evento via SimTopic. Uma central de vigilância ouve o tópico e reage em tempo virtual. Demonstra: SimTopic, SimEntity, SimProcess, Simulation.

Este exemplo usa SimTopic — o pub/sub síncrono do SimKT. Para comunicação com integração ao tempo virtual, veja Canal de Comunicação.

Fluxo da simulação

  1. O ambiente é criado com um SimTopic de detecção.
  2. A Central de Vigilância registra um ouvinte no tópico.
  3. O Radar agenda uma detecção em t=5.
  4. Em t=5, o Radar publica no tópico — a Central é notificada imediatamente.
  5. Em t=8, o Radar publica um rastreamento confirmado.

Código completo

import br.com.pedromagno.communication.topic.SimTopic
import br.com.pedromagno.core.Environment
import br.com.pedromagno.core.SimEntity
import br.com.pedromagno.core.SimTime
import br.com.pedromagno.core.Simulation
import br.com.pedromagno.process.SimProcess

// Tópico de comunicação (criado fora das entidades)
val topico = SimTopic<String>()

class CentralVigilancia(name: String) : SimEntity(name = name) {
    override fun onCreate(env: Environment) {
        super.onCreate(env)

        // Registra ouvintes no tópico ANTES da simulação começar
        topico.on("detection") { payload ->
            env.monitor.record(env.now, "$name: ALERTA — detectou $payload")
        }

        topico.on("tracking") { payload ->
            env.monitor.record(env.now, "$name: rastreando $payload")
        }
    }
}

class Radar(name: String) : SimEntity(name = name) {
    override fun onCreate(env: Environment) {
        super.onCreate(env)

        env.process(SimProcess { ctx ->
            ctx.hold(5.0)
            topico.emit("detection", "drone-01")

            ctx.hold(3.0)
            topico.emit("tracking", "drone-01 em setor-norte")
        })
    }
}

fun main() {
    val sim = Simulation("Cenário de Vigilância")

    // A ordem importa: Central deve registrar os ouvintes antes do Radar emitir
    sim.addEntity(CentralVigilancia("Central-01"))
    sim.addEntity(Radar("Radar-Alfa"))

    sim.run(until = 20.0)
    sim.printReport()
}

Saída esperada

Simulation: Cenário de Vigilância Time: SimTime(value=8.0) Entities: 2 [SimTime(value=5.0)]: Central-01: ALERTA — detectou drone-01 [SimTime(value=8.0)]: Central-01: rastreando drone-01 em setor-norte

Extensões possíveis

  • Adicionar múltiplos radares com diferentes delays de detecção.
  • Usar SimChannel se a central precisar processar detecções com atraso.
  • Adicionar CoordXY para rastrear a posição real do drone.
  • Adicionar SimResource para limitar a capacidade de rastreamento simultâneo.
Este padrão — tópico compartilhado, entidades assinando antes de emitir — é útil para radares, sonares, sensores IoT, telemetria e sistemas de comando e controle.
