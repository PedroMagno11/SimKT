Instalação

O SimKT está em fase experimental e ainda não foi publicado no Maven Central. As opções abaixo cobrem JAR local (recomendado para início) e GitHub Packages.

Requisitos

RequisitoVersão mínima
Kotlin2.3.20
JVM1.8 (Java 8)
Maven3.6+ (para compilar do fonte)
O SimKT usa a API de coroutines de baixo nível do Kotlin (startCoroutine, suspendCoroutine). Você não precisa adicionar kotlinx.coroutines ao seu projeto.

Opção 1 — JAR local (recomendado)

Clone o repositório, compile e copie o JAR para o seu projeto. É a forma mais rápida de começar.

Passo 1: compilar o SimKT

git clone https://github.com/PedroMagno11/SimKT
cd SimKT
mvn clean package

Isso gera target/simkt-0.1.0.jar e target/simkt-0.1.0-sources.jar.

Passo 2: adicionar ao seu projeto Maven

Copie o JAR para uma pasta libs/ na raiz do seu projeto e adicione ao pom.xml:

<dependency>
  <groupId>br.com.pedromagno</groupId>
  <artifactId>simkt</artifactId>
  <version>0.1.0</version>
  <scope>system</scope>
  <systemPath>${project.basedir}/libs/simkt-0.1.0.jar</systemPath>
</dependency>

Passo 2 (alternativa): Gradle

// build.gradle.kts
dependencies {
    implementation(files("libs/simkt-0.1.0.jar"))
}

Opção 2 — GitHub Packages

Se o pacote estiver publicado no GitHub Packages, configure o repositório e adicione a dependência normalmente. 

<!-- pom.xml — repositório -->
<repositories>
  <repository>
    <id>github</id>
    <url>https://maven.pkg.github.com/PedroMagno11/SimKT</url>
  </repository>
</repositories>

<!-- pom.xml — dependência -->
<dependency>
  <groupId>br.com.pedromagno</groupId>
  <artifactId>simkt</artifactId>
  <version>0.1.0</version>
</dependency>
O acesso ao GitHub Packages exige autenticação via token (~/.m2/settings.xml com <server> configurado). Veja a documentação do GitHub.

Verificação

Crie um arquivo Main.kt e verifique que a compilação funciona:

import br.com.pedromagno.core.Environment
import br.com.pedromagno.core.SimTime
import br.com.pedromagno.process.SimProcess

fun main() {
    val env = Environment()

    env.process(SimProcess { ctx ->
        ctx.hold(1.0)
        println("SimKT funcionando! t = ${ctx.now.value}")
    })

    env.run(until = SimTime(5.0))
}

Saída esperada

SimKT funcionando! t = 1.0
