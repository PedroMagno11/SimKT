Bateria e Sensores

Um dispositivo IoT executa leituras periódicas enquanto a bateria dura. Um modelo contínuo drena a bateria a cada passo de 1 unidade de tempo. Abaixo de 20%, o dispositivo entra em modo econômico (menor taxa de dreno). A simulação para automaticamente quando a bateria zera.

Demonstra: SimContainer, SimContinuousModel, SimProcess, env.stop() — todos trabalhando juntos.

Código completo

import br.com.pedromagno.continuous.SimContinuousModel
import br.com.pedromagno.core.Environment
import br.com.pedromagno.core.SimTime
import br.com.pedromagno.process.SimProcess

const val BATTERY_CAPACITY    = 100.0
const val READING_INTERVAL    = 5.0
const val NORMAL_DRAIN_RATE   = 3.0   // % por unidade de tempo
const val LOW_POWER_DRAIN_RATE = 1.0

fun main() {
    val env     = Environment()
    val battery = env.container(
        "battery", capacity = BATTERY_CAPACITY, initialLevel = BATTERY_CAPACITY)

    var lowPowerMode = false
    var readingCount = 0

    // Modelo contínuo: drena a bateria a cada passo de 1 unidade
    val drainModel = SimContinuousModel { ctx, dt ->
        val drain  = (if (lowPowerMode) LOW_POWER_DRAIN_RATE else NORMAL_DRAIN_RATE) * dt
        val actual = minOf(drain, battery.level)
        if (actual > 0.0) {
            battery.get(actual)             // retira do container
            if (battery.level <= 0.0) ctx.env.stop()  // para a simulação
        }
    }

    // Processo discreto: leituras periódicas e detecção de nível baixo
    val sensorProcess = SimProcess { ctx ->
        while (battery.level > 0.0) {
            ctx.hold(READING_INTERVAL)
            if (battery.level < 0.01) break

            readingCount++
            val pct = battery.level / BATTERY_CAPACITY * 100

            if (!lowPowerMode && pct < 20.0) {
                lowPowerMode = true
                ctx.env.monitor.record(ctx.now,
                    "MODO ECONÔMICO ATIVADO (bateria: ${"%.1f".format(pct)}%)")
            }

            ctx.env.monitor.record(ctx.now,
                "Leitura #$readingCount — bateria: ${"%.1f".format(pct)}% " +
                "[${if (lowPowerMode) "ECO" else "NORMAL"}]")
        }
    }

    env.continuous(stepSize = 1.0, models = arrayOf(drainModel))
    env.process(sensorProcess)

    env.run(until = SimTime(200.0))

    println("=== Dispositivo com Bateria ===")
    env.monitor.printAll()
    println("Parou em t=${env.now.value} com bateria ${"%.2f".format(battery.level)}%")
    println("Total de leituras: $readingCount")
}

O que está acontecendo

  • O modelo contínuo e o processo de sensor coexistem no mesmo scheduler.
  • A cada 1 unidade de tempo, o modelo drena a bateria diretamente via battery.get(drain).
  • A cada 5 unidades, o sensor acorda, verifica o nível e pode mudar o modo.
  • Quando a bateria chega a zero, ctx.env.stop() interrompe o loop.
Este padrão — modelo contínuo para dinâmica + processo discreto para lógica — é aplicável a: drones com autonomia limitada, sensores IoT, veículos elétricos, sistemas de energia renovável.
