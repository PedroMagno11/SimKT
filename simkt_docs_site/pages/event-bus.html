EventBus → SimTopic

API removida. O EventBus com publish() / subscribe() não existe mais no SimKT v0.1.0. Foi substituído por SimTopic com uma API mais simples e por SimChannel para comunicação integrada ao loop de eventos.

O que mudou

Antes (removido)Agora (v0.1.0)
EventBus.publish("topico", evento)SimTopic.emit("topico", payload)
EventBus.subscribe("topico") { }SimTopic.on("topico") { }
Integrado ao EnvironmentSimTopic é instanciado separadamente
Sem integração com o relógioSimChannel: send/receive integrados ao scheduler

Qual usar?

SimTopic

Pub/sub síncrono por nome de evento. Sem integração com tempo. Use quando só precisa notificar ouvintes sem avançar o relógio.

SimChannel

FIFO tipado integrado ao scheduler. Producers e consumers suspendem e retomam dentro do loop de eventos. Use para troca de dados entre processos.
