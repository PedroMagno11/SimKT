SimMonitor

class SimMonitor — acessível via env.monitor

SimMonitor é um log de texto simples e cronológico. Armazena mensagens associadas a instantes de tempo virtual, tornando fácil depurar o que aconteceu e quando. Está disponível em todo processo via ctx.env.monitor.

Métodos

MétodoRetornoDescrição
record(time: SimTime, message: String)UnitAdiciona uma entrada ao log no formato [SimTime(value=X)]: mensagem. As entradas são armazenadas na ordem em que foram chamadas.
all(): List<String>List<String>Retorna cópia imutável de todas as entradas. Útil para asserções em testes.
printAll()UnitImprime todas as entradas em stdout.
clear()UnitRemove todas as entradas. Chamado automaticamente por env.reset().

Uso dentro de processos

env.process(SimProcess { ctx ->
    ctx.hold(5.0)
    // ctx.now é o SimTime atual
    ctx.env.monitor.record(ctx.now, "evento ocorreu")

    ctx.hold(3.0)
    ctx.env.monitor.record(ctx.now, "segundo evento")
})

env.run(until = SimTime(20.0))
env.monitor.printAll()

Saída

[SimTime(value=5.0)]: evento ocorreu [SimTime(value=8.0)]: segundo evento

Uso em testes

@Test
fun `sensor deve registrar 3 leituras`() {
    val env = Environment()

    env.process(SimProcess { ctx ->
        repeat(3) {
            ctx.hold(10.0)
            ctx.env.monitor.record(ctx.now, "leitura")
        }
    })

    env.run(until = SimTime(40.0))

    val log = env.monitor.all()
    assertEquals(3, log.size)
    assertTrue(log[0].contains("10.0"))
    assertTrue(log[1].contains("20.0"))
    assertTrue(log[2].contains("30.0"))
}

Reutilizar o Environment

// Cenário 1
env.process(SimProcess { ctx -> ctx.hold(5.0) })
env.run(until = SimTime(10.0))
env.monitor.printAll()

// Limpa e roda cenário 2
env.reset()  // chama monitor.clear() internamente

env.process(SimProcess { ctx -> ctx.hold(3.0) })
env.run(until = SimTime(10.0))
env.monitor.printAll()
O monitor armazena as mensagens na ordem de inserção (não por tempo). Em eventos simultâneos (mesmo SimTime), a ordem de registro depende da ordem de execução dos processos.
