Canal de Comunicação

Um processo envia uma mensagem via SimChannel com um delay e outro a recebe assim que disponível. Modela a transmissão de dados por rádio, GPS ou MQTT.

Demonstra: SimChannel<T>, ctx.send(), ctx.receive().

Código

import br.com.pedromagno.core.Environment
import br.com.pedromagno.core.SimTime
import br.com.pedromagno.process.SimProcess

data class Message(val id: Int, val payload: String)

fun main() {
    val env = Environment()
    val channel = env.channel<Message>(name = "radio", capacity = 2)

    // Produtor: espera 1 unidade e envia
    env.process(SimProcess { ctx ->
        ctx.hold(1.0)
        ctx.send(channel, Message(1, "posição GPS"))
        ctx.env.monitor.record(ctx.now, "Produtor enviou mensagem")
    })

    // Consumidor: aguarda até ter mensagem
    env.process(SimProcess { ctx ->
        val message = ctx.receive(channel)
        ctx.env.monitor.record(ctx.now, "Consumidor recebeu: $message")
    })

    env.run()
    env.monitor.printAll()
}

Saída

[SimTime(value=1.0)]: Consumidor recebeu: Message(id=1, payload=posição GPS) [SimTime(value=1.0)]: Produtor enviou mensagem

O que está acontecendo

  • O consumidor começa imediatamente e chama ctx.receive(channel). O canal está vazio — ele suspende.
  • O produtor espera 1 unidade e envia a mensagem. Isso acorda o consumidor em t=1.
  • O consumidor retoma, registra a mensagem recebida.
  • O produtor registra "enviou" — na mesma unidade de tempo.
A ordem das entradas no monitor (consumidor antes do produtor) ocorre porque ctx.send() acorda o consumidor suspenso inline, antes de retornar ao produtor.
