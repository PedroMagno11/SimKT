Contribuindo

Contribuições são bem-vindas. Como a biblioteca ainda está em evolução, qualquer melhoria na API, documentação, exemplos ou testes pode ajudar bastante.

Fluxo sugerido

  1. Faça um fork do projeto.
  2. Crie uma branch para sua alteração.
  3. Implemente e teste.
  4. Abra um Pull Request explicando a mudança.

Padrões recomendados

  • Código Kotlin simples e legível.
  • Nomes claros para classes e métodos.
  • Testes para comportamentos principais.
  • Documentação quando criar novas APIs.
git checkout -b feature/nova-funcionalidade
./gradlew test
git commit -m "Add nova funcionalidade"
