SimEntity

abstract class SimEntity(id: String = UUID.randomUUID().toString(), name: String)

SimEntity é a classe base para qualquer ator nomeado dentro de uma simulação. Ela fornece um identificador único, um nome legível e hooks de ciclo de vida (onCreate / onDestroy). Use-a quando quiser modelar drones, radares, sensores, veículos ou qualquer componente que precise ser rastreado pela Simulation.

SimEntity é opcional. Você pode usar SimProcess diretamente sem estender SimEntity. A classe só é necessária quando você precisa de identidade rastreável (id/nome) e callbacks de ciclo de vida.

Propriedades

PropriedadeTipoDescrição
idStringUUID gerado automaticamente. Pode ser sobrescrito no construtor para IDs legíveis.
nameStringNome humano da entidade. Obrigatório.
createdAtSimTime?Tempo de criação. Preenchido por onCreate(). Null antes de ser adicionada à simulação.
destroyedAtSimTime?Tempo de destruição. Preenchido por onDestroy(). Null enquanto a entidade estiver ativa.
isDestroyedBooleanVerdadeiro se onDestroy() já foi chamado.

Métodos

MétodoDescrição
open fun onCreate(env: Environment)Chamado por Simulation.addEntity(). Registra createdAt = env.now. Sobrescreva para iniciar processos e configurar subscribers.
open fun onDestroy(env: Environment)Registra destroyedAt = env.now. Não é chamado automaticamente — você decide quando chamar.

Exemplo: entidade com processo interno

O padrão mais comum é sobrescrever onCreate para registrar o processo da entidade. Isso mantém a lógica do ator encapsulada na própria classe. 

class Radar(
    name: String,
    private val detectionRange: Double
) : SimEntity(name = name) {

    override fun onCreate(env: Environment) {
        super.onCreate(env)  // registra createdAt

        env.process(SimProcess { ctx ->
            while (true) {
                ctx.hold(5.0)
                ctx.env.monitor.record(ctx.now, "$name: varredura")
            }
        })
    }
}

fun main() {
    val sim = Simulation("Cenário de Detecção")
    sim.addEntity(Radar("Radar-Alfa", detectionRange = 200.0))
    sim.addEntity(Radar("Radar-Beta", detectionRange = 150.0))
    sim.run(until = 20.0)
    sim.printReport()
}

Exemplo: ciclo de vida com destruição

class MissaoLimitada(name: String, val duracao: Double) : SimEntity(name = name) {
    override fun onCreate(env: Environment) {
        super.onCreate(env)

        env.process(SimProcess { ctx ->
            ctx.env.monitor.record(ctx.now, "$name iniciada (t=${createdAt?.value})")
            ctx.hold(duracao)
            onDestroy(ctx.env)
            ctx.env.monitor.record(ctx.now, "$name encerrada (t=${destroyedAt?.value})")
        })
    }
}

fun main() {
    val sim = Simulation("Missão")
    sim.addEntity(MissaoLimitada("Alpha", duracao = 15.0))
    sim.run(until = 30.0)
    sim.printReport()
}
