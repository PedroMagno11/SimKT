Recurso Compartilhado

Três processos concorrem por uma antena de capacidade 1. Cada um espera na fila FIFO até a antena ficar livre, usa por 2 unidades de tempo e libera.

Demonstra: SimResource, ctx.request(), ctx.release(), fila de espera automática.

Código

import br.com.pedromagno.core.Environment
import br.com.pedromagno.process.SimProcess

fun main() {
    val env = Environment()
    val antenna = env.resource(name = "antena", capacity = 1)

    repeat(3) { index ->
        env.process(SimProcess { ctx ->
            ctx.env.monitor.record(ctx.now, "Mensagem $index aguardando antena")

            val token = ctx.request(antenna)  // suspende se antena ocupada
            ctx.env.monitor.record(ctx.now, "Mensagem $index usando antena")

            ctx.hold(2.0)
            ctx.release(antenna, token)

            ctx.env.monitor.record(ctx.now, "Mensagem $index liberou antena")
        })
    }

    env.run()
    env.monitor.printAll()
}

Saída

[SimTime(value=0.0)]: Mensagem 0 aguardando antena [SimTime(value=0.0)]: Mensagem 1 aguardando antena [SimTime(value=0.0)]: Mensagem 2 aguardando antena [SimTime(value=0.0)]: Mensagem 0 usando antena [SimTime(value=2.0)]: Mensagem 1 usando antena [SimTime(value=2.0)]: Mensagem 0 liberou antena [SimTime(value=4.0)]: Mensagem 2 usando antena [SimTime(value=4.0)]: Mensagem 1 liberou antena [SimTime(value=6.0)]: Mensagem 2 liberou antena

O que está acontecendo

  • Os três processos são iniciados imediatamente e todos registram "aguardando" em t=0.
  • Mensagem 0 adquire a antena (capacidade disponível) e começa a transmitir.
  • Mensagens 1 e 2 ficam suspensas na fila do SimResource.
  • Em t=2, Mensagem 0 libera. O SimResource acorda Mensagem 1 automaticamente.
  • Em t=4, Mensagem 1 libera, acordando Mensagem 2.
  • Em t=6, Mensagem 2 conclui. A fila está vazia — env.run() termina.
env.run() sem argumento until roda até a fila de eventos se esgotar. Ideal quando o tempo final depende da lógica da simulação.
