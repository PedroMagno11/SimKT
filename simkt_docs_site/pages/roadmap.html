Roadmap

O que está disponível hoje, o que está planejado, e as ideias de longo prazo para o SimKT.

O SimKT é experimental e em desenvolvimento ativo. A API pode mudar entre versões. Veja o repositório no GitHub para o estado atual do código.

v0.1.0 — atual

Arquitetura central redesenhada com suporte a processos, primitivos de simulação e utilitários.

ComponenteStatusDescrição
EnvironmentdisponívelFachada principal — cria primitivos, agenda eventos, executa a simulação
SimulationdisponívelContêiner nomeado de entidades e processos com relatório integrado
SimProcessdisponívelfun interface com suporte a suspend — coroutines de baixo nível (stdlib)
SimProcessContextdisponívelFornece hold, await, request/release, send/receive, put/get
SimEvent<T>disponívelEvento tipado com ciclo de vida PENDING → TRIGGERED / CANCELLED
SimTimedisponívelValor inline adimensional para tempo virtual
SimConfigdisponívelParâmetros de execução: until, maxEvents, randomSeed
SimEntitydisponívelClasse base para entidades com ciclo de vida onCreate / onDestroy
SimResourcedisponívelRecurso compartilhado com capacidade e fila FIFO de espera
SimChannel<T>disponívelCanal FIFO tipado com backpressure integrado ao scheduler
SimQueue<T>disponívelStore FIFO tipado (criado via env.store())
SimContainerdisponívelContainer numérico para combustível, bateria, fluidos
SimContinuousModeldisponívelModelo contínuo de passo fixo integrado ao scheduler discreto
SimTopic<T>disponívelPub/sub síncrono com on() / emit() (substitui EventBus)
SimMonitordisponívelLog de eventos com timestamp — record(), all(), printAll(), clear()
SimRandomProviderdisponívelRNG com seed — nextInt, nextLong, nextDouble, nextBoolean
CoordenadasdisponívelCoordXY, CoordXYZ, CoordGeo (Haversine), CoordPolar

v0.2 — planejado

Foco em ergonomia, testabilidade e integração com o ecossistema Kotlin.

  • DSL de processos — bloco simulation { } com sintaxe mais concisa para cenários simples
  • Coleta de estatísticas — utilitários para calcular média, variância, throughput e utilização de recursos ao longo do tempo
  • SimMonitor estruturado — suporte a campos tipados em vez de strings, facilitando análise programática
  • Eventos recorrentes — env.every(interval) { } como atalho para processos periódicos
  • Timeout em await() — ctx.await(event, timeout = SimTime(10.0))
  • Testes — suite de testes automatizados cobrindo todos os primitivos

v0.3 — exploratório

Funcionalidades avançadas que dependem da maturação da API base.

  • Visualização — exportação de log para formatos padrão (CSV, JSON) para análise externa
  • Múltiplos schedulers — execução de sub-simulações isoladas com barrier sync
  • Sensores com ruído — SimRandomProvider integrado a modelos de sensor paramétricos
  • Modelos de chegada — Poisson, exponencial e uniforme como helpers em env.random
  • Prioridade em recursos — filas de espera com prioridade em vez de FIFO puro

v1.0 — longo prazo

  • API estável com garantias de compatibilidade retroativa
  • Publicação no Maven Central
  • Documentação completa com tutoriais por domínio (IoT, logística, redes)
  • Remoção da anotação experimental

Sem plano de implementação

As seguintes funcionalidades foram consideradas mas não estão no roadmap por enquanto:

  • Execução paralela / multi-thread (o SimKT é deliberadamente single-thread para determinismo)
  • Integração com kotlinx.coroutines (conflita com a independência de runtime)
  • GUI integrada
