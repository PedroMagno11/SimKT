SimConfig

data class SimConfig(until: SimTime? = null, maxEvents: Long? = null, randomSeed: Long? = null)

SimConfig agrupa as configurações de execução da simulação em um objeto declarativo. Passe para env.run(config) quando quiser combinar limite de tempo, limite de eventos e seed de aleatoriedade em um único lugar.

Campos

CampoTipoPadrãoDescrição
untilSimTime?nullTempo máximo de simulação. A execução para quando o próximo evento ultrapassar este limite. null = sem limite de tempo.
maxEventsLong?nullNúmero máximo de eventos a processar. Útil para testes e para evitar loops infinitos. null = sem limite de eventos.
randomSeedLong?nullSe fornecido, chama env.random.reseed(seed) antes de executar. Garante resultados reproduzíveis com env.random.

Exemplos

Apenas limite de tempo

env.run(SimConfig(until = SimTime(100.0)))

Simulação reproduzível

// Com seed fixo, o mesmo cenário gera os mesmos resultados sempre
env.run(SimConfig(until = SimTime(100.0), randomSeed = 42L))

Limite de eventos para testes

// Processa no máximo 50 eventos — útil para verificar comportamento inicial
env.run(SimConfig(maxEvents = 50L))

Configuração completa

val config = SimConfig(
    until       = SimTime(3600.0), // 1 hora de tempo virtual
    maxEvents   = 10_000L,         // limite de segurança
    randomSeed  = 123L             // resultado reproduzível
)

env.run(config)
Se tanto until quanto maxEvents forem fornecidos, a execução para quando qualquer um dos dois limites for atingido.
