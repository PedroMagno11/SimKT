Sensor Básico

O exemplo mais simples do SimKT: um processo que avança três vezes no tempo com hold() e registra leituras no monitor. É o ponto de partida ideal para entender como processos funcionam.

Demonstra: SimProcess, hold(), SimMonitor, env.run(until)

Código

import br.com.pedromagno.core.Environment
import br.com.pedromagno.core.SimTime
import br.com.pedromagno.process.SimProcess
import br.com.pedromagno.process.SimProcessContext

class BasicSensorProcess : SimProcess {
    override suspend fun run(context: SimProcessContext) {
        context.env.monitor.record(context.now, "Sensor iniciado")

        context.hold(5.0)
        context.env.monitor.record(context.now, "Sensor fez a primeira leitura")

        context.hold(5.0)
        context.env.monitor.record(context.now, "Sensor detectou alvo")
    }
}

fun main() {
    val env = Environment()
    env.process(BasicSensorProcess())
    env.run(until = SimTime(20.0))
    env.monitor.printAll()
}

Saída

[SimTime(value=0.0)]: Sensor iniciado [SimTime(value=5.0)]: Sensor fez a primeira leitura [SimTime(value=10.0)]: Sensor detectou alvo

O que está acontecendo

  • O processo começa em t=0 e registra "Sensor iniciado" imediatamente.
  • context.hold(5.0) suspende o processo por 5 unidades de tempo virtuais.
  • Em t=5, o processo retoma e registra a segunda mensagem.
  • Em t=10, retoma novamente e registra a terceira.
  • O processo termina. env.run(until = 20.0) para porque não há mais eventos.

Variante com lambda

// A mesma lógica com fun interface em lambda
val env = Environment()

env.process(SimProcess { ctx ->
    ctx.env.monitor.record(ctx.now, "Sensor iniciado")
    ctx.hold(5.0)
    ctx.env.monitor.record(ctx.now, "Sensor fez a primeira leitura")
    ctx.hold(5.0)
    ctx.env.monitor.record(ctx.now, "Sensor detectou alvo")
})

env.run(until = SimTime(20.0))
env.monitor.printAll()
