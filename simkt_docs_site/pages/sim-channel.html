SimChannel

class SimChannel<T>(env, name: String, capacity: Int = Int.MAX_VALUE)

SimChannel<T> é um canal de comunicação FIFO tipado entre processos. Producers enviam valores com ctx.send() e consumers recebem com ctx.receive(). Se o buffer estiver cheio, o producer suspende. Se estiver vazio, o consumer suspende. Modela rádios, links UDP, MQTT, pipelines de telemetria, barramentos internos.

SimChannel vs SimTopic: SimChannel é integrado ao scheduler (send/receive participam do tempo virtual). SimTopic é pub/sub síncrono sem integração com o tempo — use quando quiser notificação imediata sem suspensão.

Criação

// Buffer ilimitado (sem backpressure)
val radio = env.channel<String>("radio")

// Buffer limitado — producer bloqueia quando cheio
val telemetria = env.channel<Telemetry>("telemetria", capacity = 10)

Propriedades

PropriedadeTipoDescrição
nameStringIdentificador do canal.
capacityIntCapacidade do buffer.

Métodos

MétodoRetornoDescrição
send(value: T): SimEvent<Unit>SimEventEnfileira um valor. Suspende o producer se o buffer estiver cheio e não houver receiver esperando.
receive(): SimEvent<T>SimEvent<T>Defileira um valor. Suspende o consumer se o buffer estiver vazio.
size()IntItens atualmente no buffer.
waitingReceivers()IntConsumers suspensos aguardando itens.
waitingSenders()IntProducers suspensos aguardando espaço.

Exemplo: produtor e consumidor básico

data class Message(val id: Int, val payload: String)

val env = Environment()
val canal = env.channel<Message>("radio", capacity = 2)

// Produtor
env.process(SimProcess { ctx ->
    repeat(4) { i ->
        ctx.hold(1.0)
        ctx.send(canal, Message(i, "dado-$i"))
        ctx.env.monitor.record(ctx.now, "enviado: id=$i (buffer: ${canal.size()})")
    }
})

// Consumidor (mais lento que o produtor)
env.process(SimProcess { ctx ->
    repeat(4) {
        val msg = ctx.receive(canal)
        ctx.env.monitor.record(ctx.now, "recebido: ${msg.payload}")
        ctx.hold(2.0)  // processa por 2 unidades
    }
})

env.run(until = SimTime(20.0))
env.monitor.printAll()

Saída esperada (aproximada)

[SimTime(value=1.0)]: enviado: id=0 (buffer: 0) [SimTime(value=1.0)]: recebido: dado-0 [SimTime(value=2.0)]: enviado: id=1 (buffer: 1) [SimTime(value=3.0)]: enviado: id=2 (buffer: 2) [SimTime(value=3.0)]: recebido: dado-1 ...

Canal com múltiplos producers

val env = Environment()
val uplink = env.channel<String>("uplink", capacity = 5)

// Dois UAVs enviando telemetria
listOf("Alpha", "Bravo").forEach { nome ->
    env.process(SimProcess { ctx ->
        repeat(3) { i ->
            ctx.hold(ctx.env.random.nextDouble(1.0, 4.0))
            ctx.send(uplink, "$nome: leitura $i")
        }
    })
}

// Estação de controle processa o canal
env.process(SimProcess { ctx ->
    repeat(6) {
        val msg = ctx.receive(uplink)
        ctx.env.monitor.record(ctx.now, "GS: $msg")
    }
})

env.run(SimConfig(until = SimTime(30.0), randomSeed = 42L))
env.monitor.printAll()
