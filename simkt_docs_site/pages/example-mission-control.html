Controle de Missão

Três UAVs modelados como SimEntity executam missões de duração variável. Cada UAV reporta telemetria via SimChannel, mas compartilha um único link de satélite (SimResource de capacidade 1). A estação de controle no solo processa o canal até receber todos os relatórios.

Demonstra: SimEntity, Simulation, SimResource, SimChannel, env.random.

Código completo

import br.com.pedromagno.communication.channel.SimChannel
import br.com.pedromagno.core.SimEntity
import br.com.pedromagno.core.Simulation
import br.com.pedromagno.process.SimProcess
import br.com.pedromagno.resource.SimResource

data class Telemetry(val uavId: String, val altitude: Double, val fuel: Double)

class UAV(
    name: String,
    val missionDuration: Double,
    val reportInterval: Double,
) : SimEntity(name = name) {

    val totalReports: Int get() = (missionDuration / reportInterval).toInt()

    fun process(uplink: SimResource, telemetryChannel: SimChannel<Telemetry>) =
        SimProcess { ctx ->
            var altitude = 1000.0
            var fuel     = 100.0
            var elapsed  = 0.0

            while (elapsed < missionDuration && fuel > 0.0) {
                ctx.hold(reportInterval)
                elapsed  += reportInterval
                altitude += ctx.env.random.nextDouble(-50.0, 50.0)
                fuel     -= reportInterval * 1.5

                val token = ctx.request(uplink)  // espera o link livre
                ctx.send(telemetryChannel, Telemetry(name, altitude, maxOf(fuel, 0.0)))
                ctx.release(uplink, token)
            }

            ctx.env.monitor.record(ctx.now,
                "$name: missão concluída (combustível: ${"%.1f".format(maxOf(fuel,0.0))}%)")
        }
}

fun main() {
    val sim = Simulation("UAV Mission Control")
    val env = sim.env

    val uplink    = env.resource("satellite-uplink", capacity = 1)
    val telemetry = env.channel<Telemetry>("telemetry", capacity = 20)

    val uavs = listOf(
        UAV("Alpha",   missionDuration = 40.0, reportInterval = 5.0),
        UAV("Bravo",   missionDuration = 30.0, reportInterval = 8.0),
        UAV("Charlie", missionDuration = 50.0, reportInterval = 6.0),
    )

    uavs.forEach { uav ->
        sim.addEntity(uav)
        sim.addProcess(uav.process(uplink, telemetry))
    }

    val totalReports = uavs.sumOf { it.totalReports }

    val groundStation = SimProcess { ctx ->
        repeat(totalReports) {
            val t = ctx.receive(telemetry)
            ctx.env.monitor.record(ctx.now,
                "GS ← ${t.uavId}: alt=${"%.0f".format(t.altitude)}m fuel=${"%.1f".format(t.fuel)}%")
        }
    }

    sim.addProcess(groundStation)
    sim.run(until = 60.0)
    sim.printReport()
}

Pontos de interesse

  • Cada UAV é uma SimEntity — registrado em sim.addEntity(), aparece no printReport().
  • O uplink de capacidade 1 força os UAVs a transmitir em sequência, não simultaneamente.
  • env.random.nextDouble(-50, 50) simula variação de altitude realista. Use randomSeed para reprodutibilidade.
  • A estação de controle sabe quantos relatórios esperar (totalReports) e termina sozinha.
