Posto de Combustível

Carros chegam em horários predefinidos e disputam 2 bombas (SimResource). Cada bomba consome do tanque subterrâneo (SimContainer). Um caminhão-tanque reabastece em t=50. Um dos exemplos mais completos do SimKT.

Demonstra: SimResource, SimContainer, múltiplos processos com chegada determinística.

Código completo

import br.com.pedromagno.core.Environment
import br.com.pedromagno.core.SimTime
import br.com.pedromagno.process.SimProcess

const val TANK_CAPACITY = 500.0
const val PUMP_COUNT    = 2
const val REFILL_AMOUNT = 300.0
const val REFILL_AT     = 50.0
const val SIM_DURATION  = 100.0

fun main() {
    val env   = Environment()
    val pumps = env.resource("pumps", capacity = PUMP_COUNT)
    val fuelTank = env.container(
        "underground-tank", capacity = TANK_CAPACITY, initialLevel = 300.0)

    fun car(id: Int, arrivalTime: Double, fuelNeeded: Double) = SimProcess { ctx ->
        ctx.hold(arrivalTime)
        ctx.env.monitor.record(ctx.now, "Car $id chegou (precisa ${fuelNeeded}L)")

        val pump = ctx.request(pumps)
        ctx.env.monitor.record(ctx.now,
            "Car $id na bomba (tanque: ${fuelTank.level}L)")

        ctx.get(fuelTank, fuelNeeded)   // retira combustível do tanque
        ctx.hold(fuelNeeded / 20.0)      // 20 L/min de taxa de abastecimento

        ctx.release(pumps, pump)
        ctx.env.monitor.record(ctx.now,
            "Car $id concluiu (tanque: ${fuelTank.level}L)")
    }

    val tanker = SimProcess { ctx ->
        ctx.hold(REFILL_AT)
        ctx.env.monitor.record(ctx.now, "Caminhão chegou — abastecendo ${REFILL_AMOUNT}L")
        ctx.put(fuelTank, REFILL_AMOUNT)
        ctx.env.monitor.record(ctx.now,
            "Caminhão concluiu (tanque: ${fuelTank.level}L)")
    }

    val arrivals = listOf(
        Triple(1,  0.0, 40.0),
        Triple(2,  2.0, 60.0),
        Triple(3,  5.0, 30.0),
        Triple(4,  8.0, 80.0),
        Triple(5, 30.0, 50.0),
        Triple(6, 55.0, 90.0),
        Triple(7, 60.0, 45.0),
    )

    arrivals.forEach { (id, arrival, fuel) ->
        env.process(car(id, arrival, fuel))
    }
    env.process(tanker)

    env.run(until = SimTime(SIM_DURATION))

    println("=== Posto de Combustível ===")
    env.monitor.printAll()
    println("Nível final do tanque: ${fuelTank.level}L / ${TANK_CAPACITY}L")
    println("Bombas em uso ao final: ${pumps.used()}")
}

Pontos de interesse

  • Carros com chegada simultânea (ex: Car 1 em t=0) disputam as bombas por ordem de registro.
  • O SimContainer bloqueia ctx.get() se o tanque não tiver combustível suficiente — útil para simular escassez.
  • O caminhão usa ctx.put(), que pode liberar carros bloqueados aguardando combustível.
  • As 2 bombas paralelas permitem dois carros sendo atendidos simultaneamente.
