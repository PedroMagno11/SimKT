Primeiros Passos

SimKT modela sistemas como processos que avançam no tempo virtual com hold(). Este guia leva você da instalação à primeira simulação funcional.

Antes de continuar, certifique-se de ter feito a instalação e que o JAR está disponível no classpath do seu projeto.

1. Criar o Environment

Environment é o coração da simulação. Ele mantém o relógio virtual, a fila de eventos e expõe os primitivos de simulação. 

import br.com.pedromagno.core.Environment
import br.com.pedromagno.core.SimTime
import br.com.pedromagno.process.SimProcess

val env = Environment()

2. Definir um processo

Um SimProcess é uma fun interface com um método suspenso. Dentro do processo você usa ctx.hold(delay) para avançar o tempo sem bloquear a thread. 

val sensor = SimProcess { ctx ->
    ctx.env.monitor.record(ctx.now, "Sensor iniciado")

    ctx.hold(5.0)   // avança 5 unidades de tempo
    ctx.env.monitor.record(ctx.now, "Primeira leitura")

    ctx.hold(5.0)   // avança mais 5
    ctx.env.monitor.record(ctx.now, "Alvo detectado")
}

3. Registrar o processo e executar

Registre o processo no Environment com env.process() e chame env.run() para executar o loop de eventos. 

env.process(sensor)

// Roda até t=20 ou até a fila de eventos se esgotar
env.run(until = SimTime(20.0))

// Imprime o log de eventos
env.monitor.printAll()

Saída esperada

[SimTime(value=0.0)]: Sensor iniciado [SimTime(value=5.0)]: Primeira leitura [SimTime(value=10.0)]: Alvo detectado

4. Múltiplos processos concorrentes

Registre mais de um processo. O motor intercala automaticamente os eventos em ordem de tempo. 

val env = Environment()

env.process(SimProcess { ctx ->
    ctx.hold(3.0)
    ctx.env.monitor.record(ctx.now, "Processo A concluído")
})

env.process(SimProcess { ctx ->
    ctx.hold(1.0)
    ctx.env.monitor.record(ctx.now, "Processo B: passo 1")
    ctx.hold(4.0)
    ctx.env.monitor.record(ctx.now, "Processo B: passo 2")
})

env.run(until = SimTime(10.0))
env.monitor.printAll()

Saída esperada

[SimTime(value=1.0)]: Processo B: passo 1 [SimTime(value=3.0)]: Processo A concluído [SimTime(value=5.0)]: Processo B: passo 2
Os processos executam em ordem de tempo, não de registro. O motor nunca bloqueia entre eventos — o "tempo" entre t=1 e t=3 é instantâneo.

5. Usar a classe Simulation

Para simulações com múltiplas entidades, use Simulation como fachada. Ela agrupa o Environment, as entidades e os processos. 

import br.com.pedromagno.core.Simulation

val sim = Simulation("Minha Simulação")

// Adicione processos
sim.addProcess(SimProcess { ctx ->
    ctx.hold(5.0)
    ctx.env.monitor.record(ctx.now, "Evento principal")
})

sim.run(until = 10.0)
sim.printReport()
