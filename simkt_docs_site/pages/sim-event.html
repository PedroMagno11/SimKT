SimEvent

class SimEvent<T>(time: SimTime, value: T? = null, action: (() -> Unit)? = null)

SimEvent<T> é a unidade fundamental da simulação. Representa um acontecimento agendado para um tempo virtual específico. Pode carregar um valor tipado (T) e pode ser aguardado por processos via await().

Em uso normal você raramente cria SimEvent diretamente. Use env.timeout(), env.eventAt() ou os primitivos (SimResource, SimChannel, etc.) que criam eventos internamente.

Ciclo de vida

Todo evento começa em PENDING e termina em TRIGGERED ou CANCELLED. Não há retorno.

// PENDING  →  TRIGGERED
event.trigger()
event.triggerWith(value)

// PENDING  →  CANCELLED
event.cancel()

// Leitura de estado
event.isPending    // true se ainda não disparou
event.isTriggered  // true após trigger()
event.isCancelled  // true após cancel()

Propriedades

PropriedadeTipoDescrição
timeSimTimeTempo virtual em que o evento ocorre.
statusSimEventStatusEstado atual: PENDING, TRIGGERED ou CANCELLED.
isPendingBooleanVerdadeiro enquanto o evento não foi disparado nem cancelado.
isTriggeredBooleanVerdadeiro após trigger() ou triggerWith().
isCancelledBooleanVerdadeiro após cancel().

Métodos

MétodoDescrição
valueOrNull(): T?Retorna o valor carregado pelo evento, ou null.
withValue(newValue: T): SimEvent<T>Define ou substitui o valor. Só pode ser chamado enquanto isPending.
await(continuation)Registra uma coroutine para ser retomada quando o evento disparar. Usado internamente por SimProcessContext.
trigger()Dispara o evento: muda o status, invoca action e retoma todas as coroutines aguardando.
triggerWith(newValue: T)Define o valor e dispara. Equivale a withValue(v).trigger().
cancel()Cancela o evento. Retoma todas as coroutines aguardando com null.

Exemplos

Evento de timeout básico

val env = Environment()

// env.timeout() cria um SimEvent internamente
val evento = env.timeout(5.0) {
    println("ação embutida no evento")
}

println(evento.isPending)   // true — ainda não foi disparado

env.run(until = SimTime(10.0))

println(evento.isTriggered) // true — disparado em t=5

Evento com valor tipado

val env = Environment()

// Cria um evento que carrega um resultado de detecção
val deteccao = env.eventAt(
    time  = SimTime(10.0),
    value = "drone-01"
)

env.process(SimProcess { ctx ->
    val alvo = ctx.await(deteccao)
    ctx.env.monitor.record(ctx.now, "Detectado: $alvo")
})

env.run(until = SimTime(20.0))
env.monitor.printAll()
// [SimTime(value=10.0)]: Detectado: drone-01

Cancelamento de evento

val env = Environment()
val alarme = env.timeout(10.0)

// Cancela antes de disparar
env.process(SimProcess { ctx ->
    ctx.hold(3.0)
    alarme.cancel()
    ctx.env.monitor.record(ctx.now, "Alarme cancelado")
})

env.run(until = SimTime(20.0))
// O alarme nunca dispara em t=10
Um evento cancelado permanece na fila do scheduler, mas é ignorado quando o scheduler o retira — a verificação isCancelled descarta o evento sem executar nada.
