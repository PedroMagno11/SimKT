Simulation

class Simulation(name: String, env: Environment = Environment())

Simulation é uma fachada opcional sobre Environment. Ela adiciona um nome identificável à simulação, gerencia uma lista de entidades (SimEntity) e oferece printReport() para inspecionar o estado final. Toda a lógica real continua no Environment subjacente.

Se você não precisar de entidades (SimEntity) ou de um relatório, use Environment diretamente — é mais simples.

Propriedades

PropriedadeTipoDescrição
nameStringNome da simulação, usado em printReport().
envEnvironmentO Environment subjacente. Use para criar primitivos, acessar env.now, etc.

Métodos

MétodoRetornoDescrição
addEntity(entity: SimEntity)SimulationRegistra uma entidade e chama entity.onCreate(env) imediatamente. Retorna this para encadeamento.
addProcess(process: SimProcess)SimulationDelega para env.process(process). Retorna this.
run(until: Double)UnitExecuta o loop de eventos até o tempo especificado (convertido internamente para SimTime).
printReport()UnitImprime nome, tempo atual, quantidade de entidades e todo o log do monitor.

Exemplo completo

import br.com.pedromagno.core.Simulation
import br.com.pedromagno.core.SimEntity
import br.com.pedromagno.process.SimProcess

class Sensor(name: String) : SimEntity(name = name) {
    override fun onCreate(env: br.com.pedromagno.core.Environment) {
        super.onCreate(env)
        env.process(SimProcess { ctx ->
            repeat(3) {
                ctx.hold(10.0)
                ctx.env.monitor.record(ctx.now, "$name: leitura")
            }
        })
    }
}

fun main() {
    val sim = Simulation("Rede de Sensores")

    sim.addEntity(Sensor("Sensor-A"))
    sim.addEntity(Sensor("Sensor-B"))

    sim.run(until = 40.0)
    sim.printReport()
}

Saída esperada

Simulation: Rede de Sensores Time: SimTime(value=30.0) Entities: 2 [SimTime(value=10.0)]: Sensor-A: leitura [SimTime(value=10.0)]: Sensor-B: leitura [SimTime(value=20.0)]: Sensor-A: leitura [SimTime(value=20.0)]: Sensor-B: leitura [SimTime(value=30.0)]: Sensor-A: leitura [SimTime(value=30.0)]: Sensor-B: leitura

Encadeamento fluente

val sim = Simulation("Pipeline")
    .apply {
        addEntity(Sensor("A"))
        addEntity(Sensor("B"))
        addProcess(SimProcess { ctx ->
            ctx.hold(1.0)
            ctx.env.monitor.record(ctx.now, "Monitor iniciado")
        })
    }

sim.run(until = 50.0)
sim.printReport()
