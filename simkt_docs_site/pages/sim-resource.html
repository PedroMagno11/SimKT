SimResource

class SimResource(env, name: String, capacity: Int)

SimResource modela um recurso compartilhado com capacidade limitada. Quando a capacidade está esgotada, processos que tentam adquiri-lo ficam suspensos em uma fila FIFO e são retomados automaticamente quando uma vaga é liberada. Exemplos: bombas de combustível, antenas, servidores, pistas de pouso.

Crie sempre via env.resource(name, capacity) — nunca instancie diretamente.

Criação

// Capacidade 1: exclusão mútua (mutex)
val antena = env.resource("antena", capacity = 1)

// Capacidade N: pool de recursos
val bombas = env.resource("bombas", capacity = 3)

Propriedades

PropriedadeTipoDescrição
nameStringIdentificador do recurso.
capacityIntNúmero máximo de usuários simultâneos.

Métodos

MétodoRetornoDescrição
request(): SimEvent<SimResourceRequest>SimEventCria e agenda a requisição. Use ctx.request(resource) para suspender até a vaga ser concedida.
release(request: SimResourceRequest)UnitLibera a vaga e acorda o próximo processo na fila. Deve ser chamado com o token retornado por request().
available()IntVagas disponíveis no momento.
used()IntVagas em uso no momento.
waiting()IntProcessos suspensos aguardando uma vaga.

Padrão request / release

Sempre use o token retornado por ctx.request() para liberar o recurso. Isso garante que apenas quem adquiriu a vaga possa liberá-la. 

val servidor = env.resource("servidor-http", capacity = 2)

env.process(SimProcess { ctx ->
    // Adquire (suspende se ambos os slots estiverem ocupados)
    val token = ctx.request(servidor)

    ctx.env.monitor.record(ctx.now, "processando request")
    ctx.hold(3.0)  // tempo de processamento

    // Libera a vaga (acorda o próximo na fila)
    ctx.release(servidor, token)
    ctx.env.monitor.record(ctx.now, "request concluída")
})

Exemplo: 3 processos em um recurso de capacidade 1

val env = Environment()
val antena = env.resource("antena", capacity = 1)

repeat(3) { i ->
    env.process(SimProcess { ctx ->
        ctx.env.monitor.record(ctx.now, "Msg $i: aguardando")
        val token = ctx.request(antena)
        ctx.env.monitor.record(ctx.now, "Msg $i: transmitindo")
        ctx.hold(2.0)
        ctx.release(antena, token)
        ctx.env.monitor.record(ctx.now, "Msg $i: concluída")
    })
}

env.run()
env.monitor.printAll()

Monitorar estado

println(antena)
// SimResource(name=antena, capacity=1, inUse=1, waiting=2)

println("disponíveis: ${antena.available()}")
println("em uso: ${antena.used()}")
println("na fila: ${antena.waiting()}")
Não esqueça de liberar. Se um processo terminar sem chamar release(), a vaga nunca será devolvida e os processos em espera ficarão presos para sempre. Use try/finally em cenários onde exceções são possíveis.
