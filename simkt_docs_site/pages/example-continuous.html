Movimento Contínuo

Um objeto se desloca a velocidade constante. A posição é atualizada a cada passo de 1 unidade de tempo pelo SimContinuousModel, integrado naturalmente ao loop de eventos discretos.

Demonstra: SimContinuousModel, env.continuous(), stepSize, until.

Código

import br.com.pedromagno.continuous.SimContinuousModel
import br.com.pedromagno.core.Environment
import br.com.pedromagno.core.SimTime

fun main() {
    val env = Environment()
    var position = 0.0
    val speed    = 2.0  // unidades por unidade de tempo

    env.continuous(
        stepSize = 1.0,
        until    = SimTime(5.0),
        SimContinuousModel { ctx, dt ->
            position += speed * dt
            ctx.env.monitor.record(env.now, "posição=$position")
        }
    )

    env.run(until = SimTime(10.0))
    env.monitor.printAll()
}

Saída

[SimTime(value=1.0)]: posição=2.0 [SimTime(value=2.0)]: posição=4.0 [SimTime(value=3.0)]: posição=6.0 [SimTime(value=4.0)]: posição=8.0 [SimTime(value=5.0)]: posição=10.0

O que está acontecendo

  • env.continuous(stepSize = 1.0, until = SimTime(5.0), ...) cria um processo interno que chama step(ctx, dt) a cada 1 unidade.
  • O modelo para em t=5 (parâmetro until do continuous()), mas env.run(until = 10.0) poderia continuar outros processos.
  • dt == stepSize == 1.0 neste exemplo — a velocidade 2.0 × 1.0 = 2.0 por passo.

Exemplo com passo menor (precisão maior)

val env = Environment()
var posX = 0.0
var posY = 0.0
val velX = 1.5
val velY = 1.0

env.continuous(
    stepSize = 0.1,  // 10 passos por unidade de tempo — mais suave
    until    = SimTime(5.0),
    SimContinuousModel { ctx, dt ->
        posX += velX * dt
        posY += velY * dt
    }
)

env.run(until = SimTime(5.0))
println("Posição final: ($posX, $posY)")
// Posição final: (7.5, 5.0)
Passos menores aumentam a precisão numérica mas geram mais eventos no scheduler. Para simulações longas, balanceie stepSize com a frequência de mudança das variáveis contínuas.
