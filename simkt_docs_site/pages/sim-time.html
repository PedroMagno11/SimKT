SimTime

@JvmInline value class SimTime(val value: Double)

SimTime é o tipo que representa instantes de tempo na simulação. É um inline value class que encapsula um Double — sem overhead em tempo de execução. O campo value é a unidade de tempo (adimensional).

Unidade adimensional. O SimKT não impõe unidade (segundos, minutos, ticks). Você decide o que cada unidade representa na sua simulação. Se hold(60.0) significa 60 segundos ou 1 minuto depende da sua convenção.

Construtor

ParâmetroTipoDescrição
valueDoubleValor numérico do tempo. Deve ser ≥ 0. Lança IllegalArgumentException se negativo.

Propriedades

PropriedadeTipoDescrição
valueDoubleO valor numérico.

Operadores

OperadorResultadoDescrição
SimTime + SimTimeSimTimeSoma dois instantes de tempo.
SimTime + DoubleSimTimeAdiciona um delay (Double deve ser ≥ 0).
compareTo(other: SimTime)IntCompara dois instantes. Implementa Comparable<SimTime>.

Companion object

ConstanteValorDescrição
SimTime.ZEROSimTime(0.0)O instante de tempo zero. Valor inicial de env.now.

Exemplos

val t1 = SimTime(10.0)
val t2 = SimTime(5.0)

// Aritmética
val soma = t1 + t2      // SimTime(15.0)
val deslocado = t1 + 3.0 // SimTime(13.0)

// Comparação
println(t1 > t2)        // true
println(t1 == SimTime(10.0)) // true

// Verificação de zero
println(SimTime.ZERO.value) // 0.0

// Usado com env.run()
val env = Environment()
env.run(until = SimTime(60.0))

// Acessar o tempo atual
println(env.now.value) // Double — seguro para usar em println
Não use SimTime como chave de mapa ou em estruturas que dependem de igualdade de referência. Por ser um inline value class, a igualdade é baseada no value: Double. Evite comparar dois Double com ponto flutuante em condições críticas — prefira tolerâncias ou timestamps inteiros se precisar de exatidão.
