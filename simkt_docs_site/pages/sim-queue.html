SimQueue

class SimQueue<T>(env, name: String, capacity: Int = Int.MAX_VALUE)

SimQueue<T> é uma fila de objetos FIFO para comunicação entre processos. Producers inserem com ctx.put() e consumers retiram com ctx.get(), com suspensão automática quando cheia ou vazia. Criado via env.store(). Modela filas de tarefas, estoques, pipelines de processamento.

SimQueue vs SimChannel: Ambos são FIFOs tipados. A distinção é semântica: use SimChannel para troca de mensagens ponto-a-ponto e SimQueue para modelar estoques ou buffers de produção.

Criação

// Fila ilimitada
val tarefas = env.store<String>("tarefas")

// Fila limitada — producer suspende quando cheia
val buffer = env.store<DataPacket>("buffer", capacity = 5)

Propriedades

PropriedadeTipoDescrição
nameStringIdentificador da fila.
capacityIntCapacidade máxima.

Métodos

MétodoRetornoDescrição
put(item: T): SimEvent<Unit>SimEventInsere item. Suspende o producer se a fila estiver cheia.
get(): SimEvent<T>SimEvent<T>Retira o item mais antigo. Suspende o consumer se a fila estiver vazia.
size()IntItens atualmente na fila.
waitingGets()IntConsumers suspensos aguardando itens.
waitingPuts()IntProducers suspensos aguardando espaço.

Exemplo: produtor-consumidor com fila limitada

data class Pacote(val id: Int, val tamanho: Int)

val env = Environment()
val buffer = env.store<Pacote>("buffer", capacity = 3)

// Produtor: gera pacotes a cada 2 unidades
env.process(SimProcess { ctx ->
    var id = 0
    while (true) {
        ctx.hold(2.0)
        val p = Pacote(++id, 100)
        ctx.env.monitor.record(ctx.now,
            "Produtor: enfileirando $id (fila: ${buffer.size()}/${buffer.capacity})")
        ctx.put(buffer, p)  // suspende se fila cheia
    }
})

// Consumidor: processa cada pacote em 5 unidades
env.process(SimProcess { ctx ->
    while (true) {
        val p = ctx.get(buffer)  // suspende se fila vazia
        ctx.env.monitor.record(ctx.now, "Consumidor: processando ${p.id}")
        ctx.hold(5.0)
    }
})

env.run(until = SimTime(30.0))
env.monitor.printAll()

Múltiplos consumers

val env = Environment()
val fila = env.store<String>("jobs", capacity = 10)

// 1 produtor
env.process(SimProcess { ctx ->
    repeat(8) { i ->
        ctx.hold(1.0)
        ctx.put(fila, "job-$i")
    }
})

// 3 workers
repeat(3) { w ->
    env.process(SimProcess { ctx ->
        while (true) {
            val job = ctx.get(fila)
            ctx.env.monitor.record(ctx.now, "Worker $w: executando $job")
            ctx.hold(ctx.env.random.nextDouble(2.0, 5.0))
        }
    })
}

env.run(SimConfig(until = SimTime(20.0), randomSeed = 42L))
env.monitor.printAll()
