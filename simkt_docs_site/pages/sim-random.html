SimRandomProvider

class SimRandomProvider(seed: Long? = null) — acessível via env.random

SimRandomProvider é o gerador de números pseudo-aleatórios da simulação. Com uma seed fixa, toda execução produz exatamente os mesmos resultados — essencial para simulações reproduzíveis. Use via ctx.env.random dentro de processos.

Como definir a seed

Passe randomSeed no SimConfig — é a forma recomendada:

env.run(SimConfig(until = SimTime(100.0), randomSeed = 42L))

Ou diretamente no construtor do Environment:

val env = Environment(random = SimRandomProvider(seed = 42L))

Métodos

MétodoRetornoDescrição
reseed(seed: Long)UnitRedefine o gerador com uma nova seed. Chamado automaticamente por env.run(SimConfig(randomSeed = N)).
nextInt()IntInteiro aleatório sem restrição de intervalo.
nextInt(from: Int, until: Int)IntInteiro em [from, until).
nextLong()LongLong aleatório sem restrição.
nextLong(from: Long, until: Long)LongLong em [from, until).
nextDouble()DoubleDouble em [0.0, 1.0).
nextDouble(from: Double, until: Double)DoubleDouble em [from, until).
nextBoolean()BooleanVerdadeiro ou falso com probabilidade 50%.

Exemplos

Intervalos de chegada aleatórios

val env = Environment()

env.process(SimProcess { ctx ->
    repeat(5) { i ->
        val intervalo = ctx.env.random.nextDouble(1.0, 8.0)
        ctx.hold(intervalo)
        ctx.env.monitor.record(ctx.now, "chegada $i (intervalo: ${"%.2f".format(intervalo)})")
    }
})

env.run(SimConfig(until = SimTime(100.0), randomSeed = 7L))
env.monitor.printAll()

Simulação reproduzível

// Ambas as execuções produzem exatamente os mesmos resultados
fun rodar() {
    val env = Environment()
    env.process(SimProcess { ctx ->
        val v = ctx.env.random.nextDouble(0.0, 100.0)
        ctx.env.monitor.record(SimTime(0.0), "valor: $v")
    })
    env.run(SimConfig(randomSeed = 42L))
    env.monitor.printAll()
}

rodar()
rodar() // saída idêntica à primeira
Sem seed, o gerador usa Random.Default do Kotlin — diferente a cada execução. Use sempre uma seed em testes automatizados.
