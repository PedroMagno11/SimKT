SimTopic

class SimTopic<T>

SimTopic<T> implementa um barramento pub/sub síncrono por nome de evento. Componentes registram ouvintes com on() e publicam mensagens com emit(). A entrega é imediata e síncrona — sem integração com o relógio virtual.

Diferença importante. SimTopic entrega eventos de forma síncrona — emit() chama todos os ouvintes na mesma thread, na mesma unidade de tempo, sem criar eventos no scheduler. Para comunicação com integração ao tempo virtual, use SimChannel.

Quando usar SimTopic vs SimChannel

SimTopicSimChannel
EntregaSíncrona, imediataAssíncrona, via scheduler
Múltiplos ouvintesSim (N ouvintes por nome)Não (1 receiver por vez)
Integração com tempoNãoSim
BackpressureNãoSim (buffer limitado)
Caso de uso típicoNotificações, telemetria broadcastPipelines de dados, protocolo

Métodos

MétodoDescrição
on(eventName: String, action: (Any?) -> Unit)Registra um ouvinte para o nome de evento dado. Múltiplos ouvintes por nome são suportados.
emit(eventName: String, payload: Any? = null)Entrega o payload a todos os ouvintes registrados para eventName. Se ninguém ouvir, não faz nada.

Criação

SimTopic é instanciado diretamente — não é criado pelo Environment.

val topico = SimTopic<String>()

Exemplo: radar notificando central

import br.com.pedromagno.communication.topic.SimTopic

val env = Environment()
val topico = SimTopic<String>()

// Central registra ouvinte antes da simulação começar
topico.on("detection") { payload ->
    val alvo = payload as? String ?: return@on
    env.monitor.record(env.now, "Central: detectou $alvo")
}

// Radar emite evento quando detecta algo
env.process(SimProcess { ctx ->
    ctx.hold(5.0)
    topico.emit("detection", "drone-01")

    ctx.hold(3.0)
    topico.emit("detection", "drone-02")
})

env.run(until = SimTime(20.0))
env.monitor.printAll()

Saída esperada

[SimTime(value=5.0)]: Central: detectou drone-01 [SimTime(value=8.0)]: Central: detectou drone-02

Múltiplos ouvintes

val alerta = SimTopic<String>()

// Vários sistemas assinam o mesmo tópico
alerta.on("intruso") { println("Sistema A: alerta!") }
alerta.on("intruso") { println("Sistema B: alerta!") }
alerta.on("intruso") { println("Log: intrusão registrada") }

// Todos os 3 recebem quando emit() é chamado
alerta.emit("intruso", "setor-norte")
