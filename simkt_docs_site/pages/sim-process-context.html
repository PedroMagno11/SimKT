SimProcessContext

class SimProcessContext(env: Environment)

SimProcessContext é o objeto ctx recebido dentro de um SimProcess. Ele expõe todos os métodos suspensos disponíveis — avançar tempo, aguardar eventos e interagir com primitivos. Todos os métodos são suspend e só podem ser chamados de dentro de um processo.

Propriedades

PropriedadeTipoDescrição
envEnvironmentReferência ao Environment. Use para acessar ctx.env.monitor, ctx.env.random, ctx.env.stop(), etc.
nowSimTimeAtalho para env.now. Tempo virtual atual.

Controle de tempo

MétodoDescrição
suspend fun hold(delay: Double)Suspende o processo por delay unidades de tempo virtuais. Retoma quando o evento interno é acionado pelo scheduler.
suspend fun hold(delay: Long)Variante com Long.
 
env.process(SimProcess { ctx ->
    println("t=${ctx.now.value}")  // t=0.0
    ctx.hold(5.0)
    println("t=${ctx.now.value}")  // t=5.0
    ctx.hold(3.0)
    println("t=${ctx.now.value}")  // t=8.0
})

Aguardar eventos

MétodoRetornoDescrição
suspend fun <T> await(event: SimEvent<T>): T?T?Suspende até o evento disparar. Retorna o valor do evento, ou null se cancelado.
 
val sinal = env.eventAt(SimTime(10.0), value = "detecção")

env.process(SimProcess { ctx ->
    val resultado = ctx.await(sinal)
    ctx.env.monitor.record(ctx.now, "sinal recebido: $resultado")
})

Recursos (SimResource)

MétodoRetornoDescrição
suspend fun request(resource: SimResource): SimResourceRequestSimResourceRequestRequisita o recurso. Suspende se a capacidade estiver esgotada. Retoma quando uma vaga é liberada.
fun release(resource: SimResource, request: SimResourceRequest)UnitLibera a vaga. Não é suspenso. Acorda o próximo processo em espera.
 
val antena = env.resource("antena", capacity = 1)

env.process(SimProcess { ctx ->
    val token = ctx.request(antena)   // suspende se ocupada
    ctx.hold(2.0)                      // usa o recurso
    ctx.release(antena, token)         // libera
})

Canal (SimChannel)

MétodoRetornoDescrição
suspend fun <T> send(channel: SimChannel<T>, value: T)UnitEnvia um valor. Suspende se o buffer estiver cheio e não houver receivers esperando.
suspend fun <T> receive(channel: SimChannel<T>): TTRecebe um valor. Suspende se o buffer estiver vazio. Lança erro se o evento retornar null.
 
val canal = env.channel<String>("radio", capacity = 5)

// Produtor
env.process(SimProcess { ctx ->
    ctx.hold(1.0)
    ctx.send(canal, "mensagem-01")
})

// Consumidor
env.process(SimProcess { ctx ->
    val msg = ctx.receive(canal)   // suspende até ter mensagem
    ctx.env.monitor.record(ctx.now, "recebido: $msg")
})

Recipiente (SimContainer)

MétodoRetornoDescrição
suspend fun put(container: SimContainer, amount: Double)UnitAdiciona quantidade ao recipiente. Suspende se não houver espaço suficiente.
suspend fun get(container: SimContainer, amount: Double)UnitRemove quantidade do recipiente. Suspende se o nível for insuficiente.
 
val tanque = env.container("tanque", capacity = 500.0, initialLevel = 300.0)

env.process(SimProcess { ctx ->
    ctx.get(tanque, 50.0)   // retira 50 — suspende se não tiver
    ctx.hold(5.0)
    ctx.put(tanque, 100.0)  // reabastece 100
})
