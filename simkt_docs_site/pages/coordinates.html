Coordenadas

O SimKT inclui quatro implementações de sistema de coordenadas para modelar posições em simulações espaciais (drones, radares, sensores, veículos). Todas implementam a interface Coord<C> com o método distanceTo(other: C): Double.

Interface Coord

interface Coord<C> { fun distanceTo(other: C): Double }

Todas as implementações são data class com campos mutáveis (var), permitindo atualizar a posição de um objeto ao longo da simulação.

CoordXY — Cartesiano 2D

data class CoordXY(var x: Double, var y: Double)

Distância euclidiana: √((x₂-x₁)² + (y₂-y₁)²).

val sensor = CoordXY(0.0, 0.0)
val alvo   = CoordXY(3.0, 4.0)

println(sensor.distanceTo(alvo)) // 5.0

// Atualizar posição do alvo ao longo do tempo
alvo.x = 6.0
alvo.y = 8.0
println(sensor.distanceTo(alvo)) // 10.0

CoordXYZ — Cartesiano 3D

data class CoordXYZ(var x: Double, var y: Double, var z: Double)

Distância euclidiana 3D: √((x₂-x₁)² + (y₂-y₁)² + (z₂-z₁)²). Use para drones com altitude.

val base  = CoordXYZ(0.0, 0.0, 0.0)
val drone = CoordXYZ(100.0, 100.0, 50.0)

println("distância: ${"%.2f".format(base.distanceTo(drone))}m")
// distância: 150.00m

CoordGeo — Geográfico (lat/lng)

data class CoordGeo(var lat: Double, var lng: Double)

Distância em metros usando a fórmula de Haversine (raio da Terra = 6.371.000 m).

// Aeroporto de Guarulhos → Centro de São Paulo
val guarulhos = CoordGeo(lat = -23.4356, lng = -46.4731)
val centroSP  = CoordGeo(lat = -23.5505, lng = -46.6333)

val dist = guarulhos.distanceTo(centroSP)
println("distância: ${"%.0f".format(dist)}m") // ~26.000m

CoordPolar — Polar (bearing/distance)

data class CoordPolar(var bearing: Double, var distance: Double)

bearing é o ângulo em graus (0–360). distance é o raio. Distância calculada pela Lei dos Cossenos. Útil para radares que reportam alvos em coordenadas polares. 

val radar = CoordPolar(bearing = 0.0, distance = 0.0)   // origem
val alvo  = CoordPolar(bearing = 45.0, distance = 100.0) // 45° a 100 km

println("distância: ${"%.2f".format(radar.distanceTo(alvo))}") // ~70.71

Uso em simulação

val env = Environment()

data class Drone(val nome: String, val pos: CoordXY)

val drone = Drone("UAV-01", CoordXY(0.0, 0.0))
val base  = CoordXY(100.0, 100.0)

env.process(SimProcess { ctx ->
    val velocidade = 10.0 // unidades por tempo

    repeat(10) {
        ctx.hold(1.0)
        // Move o drone em direção à base
        drone.pos.x += velocidade * 0.7
        drone.pos.y += velocidade * 0.7

        val dist = drone.pos.distanceTo(base)
        ctx.env.monitor.record(ctx.now,
            "${drone.nome}: pos=(${drone.pos.x}, ${drone.pos.y}) dist=${"%.1f".format(dist)}")

        if (dist < 5.0) {
            ctx.env.monitor.record(ctx.now, "${drone.nome}: chegou à base!")
            ctx.env.stop()
        }
    }
})

env.run()
env.monitor.printAll()
